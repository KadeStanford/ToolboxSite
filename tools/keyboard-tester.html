About Online Keyboard Tester

Use this tool to test every key on your keyboard. It captures key events and shows detailed info including the key name, code, location, and active modifiers.

How It Works

Simply press keys and the tool registers each one. Previously pressed keys are highlighted. Use this to check for stuck or unresponsive keys, or verify a new keyboard works correctly.
