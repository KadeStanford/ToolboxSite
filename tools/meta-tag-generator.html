Essential Meta Tags for Every Page

  • <title> — The most important SEO tag. Keep it under 60 characters.
  • meta description — Shown in search results. Write a compelling 140–155 char summary.
  • og:image — Use a 1200×630px image for the best social sharing preview.
  • canonical — Prevents duplicate content issues by specifying the preferred URL.
  • robots — Controls whether search engines should index and follow links on the page.
