About Color Contrast Checker

Web accessibility requires sufficient contrast between text and its background. WCAG 2.1 defines two conformance levels: AA (minimum) requires 4.5:1 for normal text and 3:1 for large text, while AAA (enhanced) requires 7:1 for normal text and 4.5:1 for large text.

How to Use

Pick or type your foreground and background colors. The tool instantly calculates the contrast ratio and shows pass/fail for each WCAG level and text size combination.
