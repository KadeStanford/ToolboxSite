About Document to PDF

This tool converts Markdown or HTML content to PDF using the html2pdf.js library. The conversion is performed entirely in your browser — no data is sent to any server.

Supported Markdown

Headings (#-######), bold (**), italic (*), code (`), lists (- or 1.), links, blockquotes (>), horizontal rules (---), and paragraphs. For full control, switch to HTML mode.
