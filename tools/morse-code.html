About Morse Code Translator

Morse code represents characters as sequences of dots (.) and dashes (-). It was invented in the 1830s and is still used in aviation, amateur radio, and emergency signaling.

How It Works

Type text in the left box to see its Morse code equivalent, or enter Morse code (dots and dashes separated by spaces, words by " / ") in the right box to decode it. Click Play to hear the signal.
