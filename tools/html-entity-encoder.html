About HTML Entities

HTML entities represent reserved or special characters that can't appear directly in HTML source code. Characters like <, >, &, and " must be encoded to display correctly in web pages.

  • Named entities — &amp;, &lt;, &gt;
  • Decimal — &#38;, &#60;
  • Hexadecimal — &#x26;, &#x3C;
