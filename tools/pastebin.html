Text Share (Pastebin)

Share text snippets, code, or notes with a unique shareable link.

⚙️ Firebase Setup Required

Cloud sharing requires a Firebase project. See js/firebase-config.js to configure. In demo mode, shares are stored locally (this browser only).

Advertisement

Uses for Text Share

  • Code reviews — Share a snippet without needing GitHub access.
  • Config files — Quickly share a settings file with a teammate.
  • Error logs — Share large error outputs when asking for help.
  • Notes & drafts — Temporarily share text between devices.
