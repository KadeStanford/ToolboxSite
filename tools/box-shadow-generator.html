About CSS Box Shadow Generator

The box-shadow CSS property adds shadow effects around an element's frame. This tool lets you visually design single or multi-layered box shadows and copy the ready-to-use CSS code.

Shadow Properties

  • X Offset: Horizontal position of the shadow
  • Y Offset: Vertical position of the shadow
  • Blur: How blurry the shadow appears
  • Spread: How far the shadow extends
  • Inset: Places the shadow inside the element
