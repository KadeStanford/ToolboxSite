About DNS Lookup Tool

DNS (Domain Name System) translates domain names into IP addresses. This tool queries public DNS resolvers to retrieve various record types for any domain.

Record Types

A — IPv4 address. AAAA — IPv6 address. MX — Mail server. TXT — Text records (SPF, DKIM). NS — Name servers. CNAME — Canonical name alias. SOA — Start of authority.
