About Online Speaker Test

This tool uses the Web Audio API to generate test tones directly in your browser. No external audio files are loaded, and nothing is sent over the network.

How to Use

Adjust the volume slider first, then click the test buttons. Use Left/Right channel tests to verify stereo. The frequency sweep plays an ascending tone from 20 Hz to 20 kHz to test full range. Use the custom frequency slider to test specific frequencies.
