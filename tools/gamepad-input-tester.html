About Gamepad Input Tester

Test any game controller connected to your computer via USB or Bluetooth. The tool uses the browser Gamepad API to read button states, analog stick positions, and trigger values in real time.

Supported Controllers

  • Xbox One / Xbox Series controllers
  • PlayStation DualShock 4 / DualSense
  • Nintendo Switch Pro Controller
  • Generic USB/Bluetooth gamepads
