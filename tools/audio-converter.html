About Audio Format Converter

This tool uses the Web Audio API to decode audio files and re-encode them in the selected format. WAV output is always lossless. WebM and OGG use the browser's built-in codecs via MediaRecorder.

Supported Input Formats

Most browsers can decode: MP3, WAV, OGG, FLAC, AAC/M4A, WebM, AIFF. Input support depends on your browser and OS.

Supported Output Formats

  • WAV — Uncompressed, lossless. Choose 16-bit or 24-bit depth.
  • OGG (Vorbis) — Open source lossy format. Good compression. (Firefox, Chrome)
  • WebM (Opus) — Modern lossy codec. Excellent for voice/music. (Chrome, Firefox, Edge)
  • FLAC — Lossless compression. Exported as WAV lossless. (Actual FLAC encoding varies by browser)
  • M4A/AAC — Widely compatible lossy format. (Safari, some browsers)

Browser Limitations

Not all output formats are available in all browsers. If a format is unsupported, the tool will show a notice. Chrome supports WebM/Opus, Firefox supports OGG/Vorbis and WebM, Safari supports M4A/AAC.
