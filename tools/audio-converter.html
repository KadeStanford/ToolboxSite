About Audio Format Converter

This tool uses the Web Audio API to decode audio files and re-encode them in the selected format. WAV output is always lossless. WebM uses the browser's built-in Opus codec via MediaRecorder.

Browser Limitations

Input format support depends on your browser. Most browsers handle MP3, WAV, OGG, FLAC, and AAC. WebM output requires a browser supporting MediaRecorder with Opus codec.
