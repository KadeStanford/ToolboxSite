About Graph/Function Plotter

This free online graphing tool lets you plot mathematical functions instantly. Enter any expression using x as the variable — supports trig functions, powers, logarithms, and more.

Supported Functions

sin, cos, tan, asin, acos, atan, sqrt, abs, log (natural), exp, ceil, floor, round, and standard arithmetic operators (+, -, *, /, ^).
