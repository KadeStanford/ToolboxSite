URL Shortener

Paste any long URL and get a short, shareable link instantly.

Firebase Setup Required

This tool requires a Firebase project to store short links. See js/firebase-config.js to configure. The demo mode below uses sessionStorage (links work in this tab only).

Letters, numbers, hyphens only

    Why Use a URL Shortener?

    • Cleaner sharing — Short links are easier to read and type in emails, SMS, and social posts.
    • Track clicks — With Firebase analytics, see how many people click your links.
    • Custom aliases — Use memorable slugs like toolnook.net/go/sale instead of random characters.
    • Avoid URL breaking — Long URLs often break in email clients and PDFs. Short links stay intact.
