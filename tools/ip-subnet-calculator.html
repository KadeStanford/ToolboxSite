About IP Subnet Calculator

Subnetting divides an IP network into smaller segments. This calculator takes an IPv4 address and CIDR prefix length (e.g., /24) and computes the network address, broadcast address, usable host range, number of hosts, and subnet mask in various formats.

How to Use

Enter an IPv4 address and select a CIDR prefix length (/0 to /32). Click Calculate to see all subnet details. Common prefixes: /24 (256 addresses), /16 (65,536 addresses), /8 (16M addresses).
