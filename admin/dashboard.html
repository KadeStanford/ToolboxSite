Firebase Setup Required

Edit /js/firebase-config.js and fill in your Firebase credentials, then set TN_FIREBASE_ENABLED = true.

  1. Go to console.firebase.google.com → Create project
  2. Project Settings → Add Web App → copy firebaseConfig values
  3. Build → Firestore Database → Create database (production mode)
  4. Build → Authentication → Sign-in method → Email/Password → Enable
  5. Authentication → Users → Add user (your admin email + password)
  6. Firestore → Rules tab → paste the security rules from firebase-config.js
  7. Paste the config into js/firebase-config.js and set TN_FIREBASE_ENABLED = true
  8. Redeploy to AWS Amplify (push to GitHub)
// Recommended Firestore Security Rules:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /analytics/{doc} {
      allow write: if true;
      allow read:  if request.auth != null;
    }
    match /shorts/{doc}  { allow read, write: if true; }
    match /pastes/{doc}  { allow read, write: if true; }
    match /{document=**} { allow read, write: if request.auth != null; }
  }
}
